
# Retail Sales Data Analytics

## Internship Project

This project analyzes a retail sales dataset using Python and performs
Exploratory Data Analysis, Customer Segmentation, and Data Cleaning.

## Tasks Completed

### Task 1 – Exploratory Data Analysis
- Dataset inspection and statistical analysis
- Monthly and quarterly sales trends
- Customer age group and gender analysis
- Product category sales analysis
- Correlation analysis
- Additional sales visualization

### Task 2 – Customer Segmentation
- RFM analysis
- Data standardization using StandardScaler
- K-Means clustering
- Elbow method for selecting clusters
- Customer segment profiling
- Marketing recommendations for each segment

### Task 3 – Data Cleaning
- Data quality assessment
- Missing-value and duplicate checks
- Data consistency checking
- Outlier detection using IQR
- Data type correction
- Before-and-after data quality comparison
- Export of cleaned dataset

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Files

- `Retail_Sales_EDA.ipynb` – Complete analysis notebook
- `retail_sales_cleaned.csv` – Cleaned retail sales dataset

## Dataset

Retail sales transaction data containing customer, date, product category,
quantity, price, and total amount information.

## Project Outcome

The project identifies sales trends, customer segments, data quality issues,
and actionable business insights that can support marketing, customer
retention, and inventory decisions.
